# Least Coins Calculator

## What it does
Calculates the least amount of coins needed for an inputted amount of cents needed in change with quarters, dimes, nickels and pennies. 
## How to run it
Start the code and input a positive amount of cents. It will calculate from there.
## Sample run
```How many cents? Enter: 67
Here are the coins I would give you for 67 cents:
2 quarters, 1 dime, 1 nickel, and 2 pennies. 
That's 6 coins in total.
```
